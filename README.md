## The entry

`main.ts` (Node 22, no dependencies, no network) deterministically writes one
deadpan one-star review to `/output/entry.txt`:

> One star. Sleep costs eight hours a night and I still wake up in debt.

70 characters, one line. The joke is a complaint filed in earnest against a
thing that cannot be fixed: you pay sleep eight hours every night and still
wake up owing it more. The sting lands in the last three words.

## Run

```sh
node main.ts
cat /output/entry.txt
```
